# QuestionForge

Automatic factual question generation from educational passages in **English, French and Arabic**.

Project 05: pretrained sequence-to-sequence question generation, with relevance and answerability assessment.
The implementation is being built against the supplied NLP final-project rubric. No paid API is required.

## Development checkpoint

This first commit preserves a small, transparent source-grounded template baseline. Subsequent commits
add pretrained Transformers, multilingual evaluation, a demonstration app and presentation artifacts.
The repository was empty when work began; no pre-existing student implementation was overwritten.
